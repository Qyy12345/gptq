# 并行运行多个GPTQ实验的简单方法

## 方法一：多终端同时运行（推荐）

### 原理
- 打开多个独立的终端会话
- 每个会话运行一个不同的实验配置
- 使用 `CUDA_VISIBLE_DEVICES` 指定不同的GPU

### 示例：同时运行3个实验

**终端 1 - GPU 0:**
```bash
# 实验1: 3位量化，分组大小128
CUDA_VISIBLE_DEVICES=0 python opt.py facebook/opt-125m c4 \
    --wbits 3 --groupsize 128 \
    > logs/3_opt125m_c4.log 2>&1
```

**终端 2 - GPU 1:**
```bash
# 实验2: 4位量化，分组大小1024，对称量化
CUDA_VISIBLE_DEVICES=1 python opt.py facebook/opt-125m c4 \
    --wbits 4 --groupsize 1024 --sym \
    > logs/4_sym_opt125m_c4.log 2>&1
```

**终端 3 - GPU 2:**
```bash
# 实验3: 4位量化，分组大小128，激活顺序优化
CUDA_VISIBLE_DEVICES=2 python opt.py facebook/opt-125m c4 \
    --wbits 4 --groupsize 128 --act-order \
    > logs/4_actorder_opt125m_c4.log 2>&1
```

### 关键参数说明
- `CUDA_VISIBLE_DEVICES=0` - 只使用GPU 0
- `> logs/xxx.log 2>&1` - 将输出保存到日志文件
- `--wbits 3/4` - 量化位数
- `--groupsize 128/1024` - 分组大小
- `--sym` - 对称量化
- `--act-order` - 激活顺序优化

### 日志文件命名建议
使用清晰的命名格式：
```
{wbits}_{config}_{model}_{dataset}.log

示例：
- 3_opt125m_c4.log          (3位，baseline)
- 4_sym_opt125m_c4.log      (4位，对称量化)
- 4_actorder_opt125m_c4.log (4位，激活顺序优化)
```

这样可以直接用 `visual/plot_layer_errors.py` 可视化结果！

## 方法二：使用 tmux/screen（可选）

如果想在一个终端中管理多个会话：

### 使用 tmux
```bash
# 创建新的tmux会话
tmux new -s exp1
CUDA_VISIBLE_DEVICES=0 python opt.py facebook/opt-125m c4 --wbits 3 > logs/3_opt125m_c4.log 2>&1

# 按Ctrl+B，然后按D 退出会话（实验继续运行）

# 创建第二个会话
tmux new -s exp2
CUDA_VISIBLE_DEVICES=1 python opt.py facebook/opt-125m c4 --wbits 4 --sym > logs/4_sym_opt125m_c4.log 2>&1

# 查看所有会话
tmux ls

# 重新连接到会话
tmux attach -t exp1
```

## 完整示例：批量运行6个实验

```bash
# 实验1
CUDA_VISIBLE_DEVICES=0 python opt.py facebook/opt-125m c4 --wbits 2 --groupsize 128 > logs/2_g128_opt125m_c4.log 2>&1 &

# 实验2
CUDA_VISIBLE_DEVICES=0 python opt.py facebook/opt-125m c4 --wbits 3 --groupsize 128 > logs/3_g128_opt125m_c4.log 2>&1 &

# 实验3
CUDA_VISIBLE_DEVICES=1 python opt.py facebook/opt-125m c4 --wbits 4 --groupsize 128 > logs/4_g128_opt125m_c4.log 2>&1 &

# 实验4
CUDA_VISIBLE_DEVICES=1 python opt.py facebook/opt-125m c4 --wbits 4 --groupsize 1024 --sym > logs/4_g1024_sym_opt125m_c4.log 2>&1 &

# 实验5
CUDA_VISIBLE_DEVICES=2 python opt.py facebook/opt-125m c4 --wbits 4 --groupsize 128 --act-order > logs/4_g128_actorder_opt125m_c4.log 2>&1 &

# 实验6
CUDA_VISIBLE_DEVICES=2 python opt.py facebook/opt-125m c4 --wbits 4 --groupsize 1024 --act-order --sym > logs/4_g1024_sym_actorder_opt125m_c4.log 2>&1 &

# 等待所有实验完成
wait

echo "所有实验完成！"
```

## 常见问题

**Q: 如何知道实验是否在运行？**
```bash
ps aux | grep "python opt.py"
```

**Q: 如何停止某个实验？**
```bash
# 找到进程ID
ps aux | grep "python opt.py"

# 停止进程
kill <PID>
```

**Q: 两个实验可以共享同一个GPU吗？**
可以，但会变慢。如果GPU内存足够（比如A100 40GB），可以：
```bash
CUDA_VISIBLE_DEVICES=0 python opt.py facebook/opt-125m c4 --wbits 3 > logs/3_opt125m_c4.log 2>&1 &
CUDA_VISIBLE_DEVICES=0 python opt.py facebook/opt-125m c4 --wbits 4 > logs/4_opt125m_c4.log 2>&1 &
```

✅ **最简单方法：** 多个终端，每个运行一个实验

✅ **日志管理：** 重定向到 `logs/*.log` 文件
✅ **可视化：** 使用 `visual/plot_layer_errors.py` 分析结果
